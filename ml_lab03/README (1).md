## Preprocessing choices
- Target: `is_canceled`
- Dropped `company` (~94% missing)
- Dropped `reservation_status` and `reservation_status_date` (leak the outcome directly)
- Kept `agent`, `country`, `children` and imputed them - low missingness, not worth dropping
- Removed only clearly extreme outliers (`adr` >= 5000, `adults` > 10) rather than everything the IQR
  rule flags, to avoid throwing away too much of the data
- Numerical features: `KNNImputer(n_neighbors=5)`, then either `StandardScaler` (Pipeline A) or
  `MinMaxScaler` (Pipeline B)
- Categorical features: `SimpleImputer(strategy="most_frequent")` + `OneHotEncoder(handle_unknown="ignore")`
- `ColumnTransformer` + `Pipeline` used throughout so all fitting only happens on the training split
- Split: `train_test_split(test_size=0.2, stratify=y, random_state=42)`, same split reused for all four
  model/pipeline runs

## Models
- `LogisticRegression(max_iter=1000)`
- `DecisionTreeClassifier(random_state=42)`

Each trained on Pipeline A and Pipeline B -> 4 combinations total.
